# 历史数据供应商准入门槛

本文件定义回放和模型校准的数据准入条件，不代表任何具体供应商已经通过验收。

## 预算边界

- 月度行情与历史数据费用上限：20 美元；
- 可以注册、实名认证并购买服务；
- 超过预算的服务不会因为功能丰富而自动获得例外；
- 免费或 GitHub 开源项目同样必须通过数据来源、许可和点时能力检查。

## 必须逐项验证的能力

1. 历史时点真实可见的证券池，包含当时已经退市、后来退市及暂停上市的证券；
2. 未复权日线及其明确单位；
3. 历史 ST、`*ST`、退市整理、上市日期和证券类型状态；
4. 沪、深、北交易日历；
5. 历史停牌与复牌记录；
6. 分红、送转、拆并股等公司行为；
7. 财务、公告或新闻的原始发布时间，避免使用后来修订内容回填过去；
8. 服务条款允许本软件按预期方式读取、缓存和分析数据。

只具备“可以查询历史 K 线”不等于可以进行无偏历史回放。缺少历史股票池或历史状态会产生幸存者偏差；缺少发布时间会产生未来信息泄漏。

## 证据规则

- 每项能力必须有合同、官方文档、实际接口测试或书面授权证据；
- 证据必须记录验证日期，过期后重新检查；
- GitHub Star、下载量、博客推荐和口碑只能用于发现候选，不属于数据正确性或授权证据；
- 未核实应记录为“证据不足”，而不是直接描述为供应商能力不存在；
- 只有预算、使用权和全部点时能力同时通过，才能标记为可用于可信历史回放。

当前代码中的 `AssessHistoricalProvider` 将上述规则实现为 fail-closed 准入检查。真实供应商仍需逐项填写并验证证据，不能用全为 `true` 的配置代替实际验收。
